# Archived: OneUIX integration (historical)

**Not active in current D2 Guardian.** The OneUIX feature port, settings, hooks, compile stubs and dependency were intentionally removed after successful baseline run [38672204822](https://github.com/SysopBP/SamsungLockD2-Public/actions/runs/38672204822). This document records historical development only; do not follow old setup instructions for current builds.

The D2-owned Samsung power menu remains: power off, restart, soft restart, SRP status, mobile data when available, Lock D2, custom icons and native emergency actions. It no longer depends on OneUIX package routing or custom ordering. D2 StrongAuth diagnostics are independent and read-only.

Earlier OneUIX integration was based on [SoClear/OneUIX](https://github.com/SoClear/OneUIX), reference revision `591d09c9cc69faf3c8faf258e39869b2df7981f4`. Upstream attribution and relevant historical notices remain. Prior contents and testing notes are available in repository history.
