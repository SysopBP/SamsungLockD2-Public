# Archived: OneUIX port validation

The OneUIX port is no longer shipped in D2 Guardian after baseline Actions run 38672204822. Do not enable or test former OneUIX configuration switches; they are removed. This is an archived validation plan, retained by name to avoid broken historical links.

For the current build, validate D2's own Samsung power menu, native emergency actions, SRP verification, PIN/pattern and fingerprint, accessibility fallback, boot/wake, watchdog, widgets and read-only StrongAuth diagnostics. Verify on the target Samsung firmware; CI cannot establish OEM hook compatibility. Historical OneUIX tests remain available in Git history.
